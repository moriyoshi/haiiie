# Long-Term Memory Index

Durable, topic-organised project knowledge. Unlike `JOURNAL.md` ( append-only,
chronological ), these documents are meant to be **edited and refined** over time.

Documents arrive here by distilling chronological `JOURNAL.md` entries into topic
documents, and by merging overlapping topic documents into broader syntheses. A
document that is neither -- an external proposal, a one-off report -- does not belong
here; that distinction is why upstream's own prescription was filed outside its LTM.
